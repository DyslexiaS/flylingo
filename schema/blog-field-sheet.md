# 部落格欄位

一篇是一篇 WordPress 文章。網址代稱不要改：`packing`、`cities`、`sparta`。

後台只加一個分類。標題、摘要、封面圖、內文用 WordPress 原本的欄位。

## 分類

單選，一篇一個。清單頁上方用這些篩選，再加一個「全部」。

| 分類 | 代稱 | 現有文章 |
| --- | --- | --- |
| 行前準備 | prep | packing |
| 選校指南 | choose | sparta |
| 城市介紹 | city | cities |
| 考試準備 | exam | 還沒有 |
| 當地生活 | life | 還沒有 |
| 心得分享 | story | 還沒有 |

選校指南放怎麼挑學校、管理強度差在哪。考試準備放雅思、多益。費用和簽證不另開分類：費用用 LINE 問，簽證寫進行前準備。

學校頁要掛文章，用手選那間學校的相關文章，最多 3 篇。不要用這組分類自動配到學校。

## WordPress 原本就有

| 中文 | WordPress | 前台 |
| --- | --- | --- |
| 標題 | 標題 | 列表、文章頁 |
| 摘要 | 摘要 | 列表、文章頁標題下 |
| 封面圖 | 精選圖片 | 列表和文章頁封面。沒圖就用網站的插畫 |
| 內文 | 內容 | 文章正文 |

內文用編輯器原本的區塊：H2（會變目錄）、H3、段落、清單、表格、引言、圖片、詳細資訊。不要加自訂 class，樣式由網站套。

不要另建閱讀時間、作者、留言，或第二組 tag。閱讀時間用字數去除 300，最少 2 分鐘，網站自己算。
